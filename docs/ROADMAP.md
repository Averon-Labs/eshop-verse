# Project Roadmap

## Overview

This roadmap outlines the high-level phases for EShop Verse development. Detailed work items are tracked as GitHub Issues.

---

## Phases

### Phase 0 — Foundation ← **CURRENT**
- Repository structure and conventions
- CI/CD pipeline setup
- Development environment documentation
- Architecture documentation
- Agent workflow establishment

### Phase 1 — Authentication
- User registration
- User login / logout
- Token management
- Password reset
- Backend auth endpoints
- Android auth UI and flow

### Phase 2 — Product Catalog
- Product data model and API
- Category management
- Product listing (grid/list views)
- Product detail screen
- Product images

### Phase 3 — Search & Filtering
- Product search
- Category filtering
- Sort options (price, name, date)
- Search results UI

### Phase 4 — Wishlist
- Add/remove wishlist items
- Wishlist screen
- Wishlist API endpoints

### Phase 5 — Cart
- Add to cart
- Cart management (quantity, remove)
- Cart screen
- Cart API endpoints

### Phase 6 — Checkout
- Checkout flow
- Shipping address
- Order summary
- Order placement

### Phase 7 — Payment
- Payment integration
- Payment processing
- Payment confirmation

### Phase 8 — Orders
- Order history
- Order detail
- Order status tracking
- Order management (admin)

### Phase 9 — Reviews
- Submit review
- View reviews
- Rating aggregation
- Review moderation (admin)

### Phase 10 — Notifications
- Push notification infrastructure
- Order status notifications
- Notification preferences

### Phase 11 — Admin Dashboard
- Admin authentication
- Product management UI
- Order management UI
- User management UI

### Phase 12 — Analytics
- Sales reporting
- User metrics
- Product performance
- Dashboard widgets

### Phase 13 — Hardening & Release
- Security audit
- Performance optimization
- Error handling review
- Documentation finalization
- Release preparation

---

> Detailed task breakdown for each phase will be tracked in GitHub Issues.
> This roadmap will be updated as phases are completed.
